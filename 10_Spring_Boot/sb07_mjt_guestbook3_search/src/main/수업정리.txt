4. Querydsl 설명
	1) Querydsl은 Java 코드로 SQL/JPA 쿼리를 타입 안전하게 작성할 수 있게 해주는 라이브러리
    sql : select * from guestbook
    jpql: select g from Guestbook g
    -> sql/jpql을 자바코딩으로 쿼리작성해 주는 도구
    
    2) 예
    @Query("select d from Dept d where d.dname = :dname")
	List<Dept> findByDname(@Param("dname") String dname);
	
	=> Querydsl 사용
	
		QDept dept = QDept.dept; // Dept d
		
		List<Dept> list =
		    queryFactory
		        .selectFrom(dept) // select d from
		        .where(dept.dname.eq("SALES")) // where d.dname = :dname
		        .fetch();
		 
	3) 검색조건이 복잡해지면 jpql은 복잡해진다.
	   그래서 동적쿼리 같은 검색조건이 복잡할 경우에는 Querydsl을 사용하면 편리하다.
	   
	4) Querydsl Q 클래스                                  Q클래스
	 @ Entity Dept -> Querydsl의 annotation processor -> QDept
	 
	5) Querydsl의 기본 구조
	  (1) JPAQueryFactory queryFactory;
	  (2) 전체 흐름
				  	Entity
					  ↓
					QEntity 생성
					  ↓
					QDept
					  ↓
					JPAQueryFactory: Querydsl 에게 이렇게 실행하라는 명령 객체
					  ↓
					자바코딩
					select()    sql/jpql
					from()
					where()
					orderBy()
					  ↓
					fetch()
	
	6) Querydsl 의 매우 종요한 장점: 동적 쿠리
	
	7) Querydsl 의 전체 구조
				   	Entity
		               │
		               ▼
		             Dept
		               │
		               │ Querydsl
		               ▼
		             QDept
		               │
		               ▼
		        JPAQueryFactory
		               │
		       ┌───────┼────────┐
		       ▼       ▼        ▼
		    select    where   orderBy
		       │       │        │
		       └───────┼────────┘
		               ▼
		             fetch()
		               │
		               ▼
		          List<Dept>
