3. React 개요
 1) 사용자 인터페이스(UI)를 만들기 위한 JavaScript 라이브러리
 2) 주로 웹 페이지의 화면을 개발할 때 사용
 3) 복잡한 버튼, 메뉴, 게시판, 로그인 화면 등을 효율적으로 만들 수 있다.
    즉, UI 구성 요소를 구축하기 위한 도구
 4) 공식 사이트: https://react.dev/
 5) React는 화면을 컴포넌트(Component) 작은 단위로 개발.
 6) 페이스북 소프트웨어 엔지니어인 조던 워크가 개발.

4. React의 주요 특징
	특징			설명
	컴포넌트(Component)	화면을 재사용 가능한 작은 단위로 분리
	JSX			JavaScript 코드 안에서 HTML과 유사한 문법으로 화면 작성
	Props			부모 컴포넌트에서 자식 컴포넌트로 데이터 전달
	State			컴포넌트가 관리하는 데이터이며 변경 시 화면 업데이트
	선언형 UI			화면이 어떤 상태에서 어떻게 보여야 하는지 표현
	Virtual DOM		화면 변경 사항을 효율적으로 반영하는 데 활용되는 기술적 개념

8. React 동작 원리
  1) React는 메모리에 가상(Virtual) DOM을 생성해서 화면을 효율적으로 관리.
  2) 브라우저의 DOM을 직접 조작하는 대신에 메모리에 가상 DOM을 생성하여 필요한 모든 조작을 수행한 후
     브라우저 DOM에 변경사항을 적용한다. 
  3) React는 어떤 변경 사항이 있는지 파악하고, 필요한 부분만 변경한다.
