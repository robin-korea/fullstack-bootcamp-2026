1. REST 
  1) Representational State Transfer 약어
  2) 직역 : 자원의 상태를 표현해서 전달하는 방식
  3) 웹에서 데이터를 주고받을 때 사용하는 설계 방식(아키텍처 스타일)
  4) 예: 게시판 관리
  게시글
    ├─ 조회
    ├─ 등록
    ├─ 수정
    └─ 삭제
    
    자원(게시글)을 URL로 표현하고 + HTTP 메서드로 작업을 구분
    
   5) REST 에서 가장 중요한 개념(3가지)
      ㄴ 자원
      ㄴ URI 	 
      ㄴ HTTP 메서드
   	예)          URI             HTTP 메서드 
   	   http://localhost/board   + GET 요청       게시글 목록 조회 기능
   	   http://localhost/board/10 + GET 요청      게시글 등록 가능
   	   http://localhost/board/10 + POST 요청     게시글 10번 조회(상세보기) 가능
   	   http://localhost/board/10 + PUT 요청      게시글 10번 수정 기능
   	   http://localhost/board/10 + DELETE 요청   게시글 10번 삭제 기능
   	   
2. REST API
     ㄴ REST 방식의 규칙을 이용해서 프로그램끼리 데이터를 주고받는 API
     
3. 스프링 REST 방식의 사용되는 어노테이션
    1) @RestController: REST 방식으로 처리하는 컨트롤러.   데이터(JSON,XML,일반텍스트 등)
    2) @ResponseBody  : JSP 와 같은 뷰가 전달 되는 것이 아니라 데이터 자체 
    3) @PathVariable  : URL 경로 속에서 파라미터를 추출할 때 사용하는 어노테이션
    4) @CrossOrigin   : Ajax 처리시 서로 다른 도메인을 요청할 때의 문제를 해결하는 어노테이션
    5) @RequestBody   : JSON 데이터를 원하는 타입으로 변환(바인딩) 처리
